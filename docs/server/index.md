# Managing Your Server

Once your server has been created, you can manage it through the **[Arlo Hosting Panel](https://panel.arlostudios.dev)**.

The Panel gives you access to the tools you need to control your server, manage your files, monitor your application, and keep your service running.

## Server controls

The Panel provides several controls for managing your server:

- **Start** your server
- **Stop** your server
- **Restart** your server

:::warning
Stopping or restarting your server will temporarily stop your application. If you're running a Discord bot, it may disconnect while the server is stopped.
:::

## Console & logs

The console allows you to view your application's output while it is running.

It's particularly useful for:

- Monitoring our application
- Checking startup messages
- Finding errors
- Troubleshooting problems

You can learn more in **[Console & Logs](server/console)**.

## Files

Your server includes a file manage that allows you to manage the files used by your application.

You can upload, download, edit, and delete files directly from the Panel.

See **[Managing Files](server/files)** for more information.

## Databases

Depending on your hosting plan, you may have access to databases for your applications.

Database management is available directly through the Panel.

See **[Databases](server/databases)** for more information.

## Backups

If backups are included with your hosting plan, you can manage them through the Panel.

See **[Backups](server/backups)** for more information.
